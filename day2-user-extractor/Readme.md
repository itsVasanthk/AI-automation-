# Day 2 - User Data Extractor

A Python automation project that fetches user data from a public API, processes the JSON response, and saves formatted results into a text file.

## Features

- Fetch user data using API requests
- Parse JSON responses
- Extract:
  - Name
  - Email
  - Phone
  - Website
  - Company
- Save structured output into a text file automatically

## Technologies Used

- Python
- Requests library
- REST API
- JSON handling
- File handling

## Files

- `users.py` → Main Python automation script
- `users.txt` → Generated output file

## Concepts Learned

- API requests using `requests`
- JSON parsing
- Loops and iteration
- Dictionary and nested dictionary access
- Writing automation output to files

## API Used

JSONPlaceholder:
https://jsonplaceholder.typicode.com/users
