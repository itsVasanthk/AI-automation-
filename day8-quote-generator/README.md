# Quote Generator System

Python script that fetches random quotes using an API and stores quote history.

## Features
- Fetch random quotes from API
- Display author information
- Save quote history with timestamps
- Handles SSL workaround for learning purposes

## Technologies Used
- Python
- Requests
- Datetime
- File handling

## Concepts Learned
- API requests
- JSON parsing
- Timestamps
- History logging
- SSL debugging
